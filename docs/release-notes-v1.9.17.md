验证：已发布APK的包名、显示名称、版本和签名核对通过。本次仅更名与版本递增，未修改照片处理逻辑。沿用v1.9.16的45项主机排版与16项地点存储测试记录；本次未重新完成真机UI、图库导出或V1/V2同机并存验收。

## English

This release renames the app displayed on the phone to “相册滑选（单机版）” (PhotoSwipe — Offline Edition), including its Settings label. Version1.9.17 / versionCode27 retains package com.maodun.photoswipe and the existing signing certificate. Install over the old V1 without uninstalling or clearing app data.

Features remain on the v1.9.16 baseline: My / Swipe / Settlement tabs, local favorites, memory notes, manual location captions for no-GPS photos, and compact image exports. No accounts, photo uploads, cloud sync or public ratings are added. This Release does not contain the V2 development app.

Favorites and pending actions remain local. Deletion is permanent: back up important photos. Uninstalling or clearing data loses local records. Photo-GPS place-name lookup may still use the system Geocoder network service; photos are not uploaded and live device location is not read.

Verification: package, label, version and signing certificate of the delivered APK were verified. This release changes only naming and version metadata, not photo-processing logic. The v1.9.16 records contain45 host-layout checks and16 place-storage checks. On-device UI, gallery exports and V1/V2 side-by-side installation were not newly validated for this release.
